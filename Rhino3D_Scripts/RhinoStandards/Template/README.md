# Inventaur Architecture Metric Template

File: Inventaur_Architecture_MM.3dm

The shared default Rhino metric architectural template. It belongs to the Rhino Standards package, not to a separate modelling project.

## Verified baseline
- 44 architectural layers.
- 14 persistent annotation/text styles.
- 59 Rhino-native hatch definitions in the document hatch table.
- Zero geometry objects.
- Current layer: 04_ARCHITECTURE::GENERAL.
- Current dimension style: INV_STD_MM.
- Model and page units: millimetres.

Inventaur_Architecture_MM.3dm.previous is the previous template rollback copy. Keep it alongside the active template. Ordinary startup validates and reuses the template; rebuild only as an intentional standards revision.
